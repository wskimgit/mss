# MSS 마스터 v7.1.0

상태: 동결 · 현재
날짜: 2026-09-26
부모 버전: v7.0.0
변경유형: 기능확장판

## 권위 구성

v7.1.0은 다음 세 문서를 하나의 실행계약으로 결합한다.

1. 분석 본체:
   master/MSS_MASTER_v7.0.0_FROZEN_CURRENT.md

2. 필수 검증계약:
   master/MSS_VALIDATION_CONTRACT_v7.1.0_FROZEN.md

3. 필수 보충 검증계약:
   master/MSS_VALIDATION_ADDENDUM_v7.1.0_FROZEN.md

## 우선순위

사실 경계
→ 생성형 인공지능 최종판단
→ v7.1 필수 검증계약
→ v7.1 보충 검증계약
→ v7.0 분석 본체
→ 자료원

v7.1 계약과 v7.0 본체가 충돌하면 v7.1 계약이 우선한다.
v7.0 본체의 비충돌 조항은 모두 상속한다.

## 핵심 변경

- 3단계 실제 가격구조 필수
- 자료가용성 편향 금지
- 추천매력도와 판단신뢰도 분리
- 수치점수 완전 산식
- 실제 독립 재계산 2회 기반 재현성
- 실제 자료원 기반 기업행위 검증
- 광역 최신성 및 신규발굴 공백 공개
- 시장별 독립 압축
- 국가별 고정 후보수 배분 금지
- 업종 자기강화 금지
- 4단계 전 종목 단일상태
- 자료취득시각·실행시간 출처 필수
- 시간제한 미설정 시 시간제한 표현 금지
- 이전 실행 비교기록 분리
- 실제 사용자 출력문안 검증
- 자가검증기 자체 역검증
- 광역 다기간 정보부족 공개
- 경험 가중치 민감도검사

## 완료 조건

세 문서의 필수 검증을 모두 통과해야만 실행을 완료로 확정할 수 있다.
하나라도 실패하면 구조적 문제 또는 실행 미완료로 기록한다.

## 최종 출력

사용자 표시 규칙은 한글을 유지한다.
마지막 제목은 "MSS 최종 결론"으로 표시한다.
마지막 핵심줄 뒤에는 추가문장을 출력하지 않는다.
