# MSS 검증 계약 v7.1.0 — 후보본

상태: 동결
부모: MSS v7.0.0
목적: 실행결과의 데이터 무결성, 재현성, 단계 정합성, 최신성, 출력 정합성을 강제 검증한다.

## 1. 3단계 실제 가격구조

3단계의 모든 종목은 시장 구분 없이 다음을 실제 자료로 확인한다.
- 가격자료 기준일
- 최신 완료거래일 종가
- 최근 고점
- 최근 저점
- 고점 대비 조정률
- 저점 대비 회복률
- 최근 의미있는 낙폭
- 직접 수익률
- 돌파·회복·재가속 상태
- 자료원
- 자료취득시각
- 자료취득시각 출처

빈칸을 검증완료로 간주하지 않는다.
필수값 부족 시 미검증으로 기록하고 다음 단계 자동진입을 금지한다.
자료가 쉬운 다른 종목으로 조용히 대체하지 않는다.

## 2. 자료가용성 편향 금지

다음 단계 진입목록은 직전 단계 결과로 먼저 고정한다.
자료 확보 가능성을 이유로 순위를 바꾸지 않는다.
자료 부족은 미검증으로 남기고 후보 수 감소를 허용한다.

## 3. 수치점수 완전 산식

모든 수치점수는 원시 입력부터 재계산 가능해야 한다.

필수:
- 원시 입력필드
- 정규화식
- 임계값
- 축 점수 산식
- 최종 점수 산식
- 신뢰도 등급 규칙
- 가중치와 벌점
- 계산식 버전
- 경험값 여부

산식 없는 숫자는 금지하고 정성판단으로만 기록한다.
위험은 안전성 또는 벌점 방향으로만 사용한다.
근거품질은 판단신뢰도에만 사용하고 매력도 점수에는 가산하지 않는다.

## 4. 실제 재계산 재현성

같은 입력해시와 같은 계산식 버전으로 독립 계산을 두 번 수행한다.
두 결과의 종목순서, 점수, 상태, 출력해시를 비교한다.
모두 같아야 통과다.
파일 존재만으로 재현성 통과를 선언하지 않는다.

## 5. 기업행위와 이상치

수익률 임계값 초과는 의심신호일 뿐 기업행위 판정이 아니다.
액면분할·병합·권리락·증자·상장변경은 실제 자료원으로 확인한다.
확인 전에는 의심 수익률만 해당 계산에서 제외한다.
의심 수익률을 임의로 0으로 바꾸지 않는다.

## 6. 광역 최신성

전체시장 원자료가 최신 완료거래일보다 지연되면 완전한 최신 신규발굴로 간주하지 않는다.

순서:
1. 가능한 경우 전체시장 저비용 차등갱신
2. 불가능하면 지연 거래일 수 기록
3. 신규발굴 공백 기록
4. 시장포괄도와 판단신뢰도 하향
5. 최신 전체시장 표현 금지

상위후보 최신검증은 광역 신규발굴 공백을 없애지 못한다.

## 7. 시장별 독립 압축

한국과 미국은 각자 독립적으로 단계 압축을 수행한다.
국가별 고정 후보수 배분을 금지한다.
기본 압축 숫자는 목표이며 정확한 숫자를 강제하지 않는다.
강제검증은 계보, 단계 감소, 이유기록을 검사한다.

## 8. 업종 자기강화 금지

상위후보의 업종 비율을 다시 업종 주도력 가산점으로 사용하지 않는다.
가능하면 전체시장 또는 독립 업종자료를 사용한다.
독립 자료가 없으면 해당 점수요소를 제외한다.

## 9. 실행자산 단일상태

4단계 전체 종목은 근거기록에 모두 존재해야 한다.

상태는 다음 중 하나만 사용한다.
- 현재 선정
- 안정화
- 조정 대기
- 이벤트 대기
- 관찰
- 제외

범용 대기목록으로 서로 다른 상태를 합치지 않는다.
단계파일, 근거기록, 실행기록의 상태·신뢰도·가격·기준일은 문자 그대로 일치해야 한다.

## 10. 시간과 시각출처

자료취득시각과 실행시간은 출처가 있는 값만 사용한다.
출처가 없으면 미검증으로 기록한다.
시간제한 값이 미설정이면 시간제한 실행이라고 표현하지 않는다.

## 11. 실제 출력 검증

실제 사용자에게 보낼 최종문안을 생성한 뒤 검사한다.
- 8개 구역 존재
- 한글 표시규칙 준수
- 최신성·포괄도 제한 정확
- 후보 상태 일치
- 마지막 결론 줄바꿈 준수
- 마지막 핵심줄 뒤 추가문장 없음

예정문구나 manifest만 검사해서는 안 된다.

마지막 제목:
MSS 최종 결론

## 12. 자가검증기 역검증

자가검증기는 알려진 오류를 실제로 검출해야 한다.

필수 오류표본:
- 3단계 가격구조 필드 공란
- 산식 없는 축점수
- 재계산 없는 재현성 통과
- 자료취득시각 누락
- 광역자료 지연
- 4단계 종목 근거기록 누락
- 상태 의미 불일치
- 시간제한 미설정
- 국가별 고정 후보수 배분
- 업종 자기강화
- 실제 출력 미검증

하나라도 검출하지 못하면 자가검증기 실패다.

## 13. 완료 차단

위 필수검사 중 하나라도 실패하면 실행을 완료로 확정할 수 없다.
실패항목의 근본원인, 영향범위, 수정방법을 기록한다.
