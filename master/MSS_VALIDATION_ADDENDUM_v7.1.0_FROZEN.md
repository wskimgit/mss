# MSS v7.1.0 보충 검증 계약

상태: 동결
부모 검증계약: MSS_VALIDATION_CONTRACT_v7.1.0_CANDIDATE.md

## 1. 광역 다기간 정보

시장 전체 1·2단계에서 다기간 수익률이 없는 경우 그 사실을 기록한다.
시가총액·거래량·당일등락만으로 다기간 추세가 있는 것처럼 표현하지 않는다.
다기간 자료가 부족하면 해당 시장의 광역 신규발굴 신뢰도를 낮춘다.
가능하면 전체시장 저비용 다기간 자료를 먼저 보충한다.

## 2. 경험값과 민감도

경험적으로 정한 가중치·벌점·임계값은 경험값으로 표시한다.
핵심 가중치와 임계값을 소폭 변화시켜 상위후보 순위가 과도하게 뒤집히는지 민감도검사를 수행한다.
작은 변화로 최종후보가 크게 바뀌면 판단신뢰도를 낮춘다.
민감도검증 전에는 경험값을 최적값이라고 표현하지 않는다.

## 3. 이전 실행 비교기록

이전 실행과의 비교는 현재 실행의 후보선정과 상태확정이 모두 끝난 뒤에만 수행한다.
비교결과는 별도 비교기록 파일에 저장한다.
이전 실행의 순위·상태·점수는 현재 실행의 점수 입력으로 사용하지 않는다.

## 4. 추천매력도와 판단신뢰도의 독립 저장

각 4단계 종목에 대해 다음을 별도 필드로 저장한다.
- 추천매력도 또는 정성 매력도
- 판단신뢰도
- 미검증 항목 수
- 최신성 등급
- 반대근거

근거가 많다는 이유만으로 추천매력도를 높이지 않는다.
근거가 적은 경우 추천매력도와 별개로 판단신뢰도만 낮춘다.
