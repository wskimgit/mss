# MSS v7.2.0 검증 바인딩 — 동결

## 목적

v7.1의 유효한 내부 검증 기능을 유지하되,
MSS 원형 기준본과 원형 보호 계약을 침범하는 하위조항을 무효화한다.

## 상위 권위

1. master/MSS_MASTER_v6.2.1_FROZEN_CURRENT.md
2. master/MSS_CORE_GUARD_v1.0_FROZEN.md

위 두 문서가 원형 의미와 출력형식을 결정한다.

## 하위 검증자료

- master/MSS_VALIDATION_CONTRACT_v7.1.0_FROZEN.md
- master/MSS_VALIDATION_ADDENDUM_v7.1.0_FROZEN.md

하위 검증자료는 내부 자료무결성·최신성·재현성·상태일치·자가검증에만 사용한다.

## 명시적 무효화

다음 하위조항은 원형과 충돌하므로 무효다.

- 마지막 결론 제목을 "MSS 최종 결론"으로 변경하는 조항
- 출력 8개 구역의 제목·순서·수를 변경하는 모든 조항
- "MSS 한줄 결론"을 다른 제목으로 바꾸는 모든 조항
- 원형 공식 실행을 연결문서나 요약문으로 대체하는 모든 조항

## 출력 검증 기준

실제 사용자 출력 검증은 반드시 원형 기준본의 제16절·제17절을 기준으로 한다.

필수:
1. 머리말
2. 시장 및 주도력
3. 시장탐색 압축경로
4. 상위 후보
5. 사용 근거
6. 생성형 인공지능 최종판단 및 신뢰도
7. 자료 무결성
8. 생성형 인공지능 자가검증 및 지시문 개선

마지막:
MSS 한줄 결론
│ 최우선: [종목/없음]
│ 다음 후보: [종목들/없음]
│ 신뢰도: [높음/중상/중간/중하/낮음]
│ 핵심: [가장 중요한 한 문장]

## 반복수행 규칙

실행할 때마다:
원형을 읽는다
→ 원형 해시를 확인한다
→ 원형 보호 계약을 확인한다
→ 하위 검증계약을 적용한다
→ 분석을 수행한다
→ 실제 출력문안을 원형 형식으로 검증한다
→ 결과만 출력한다

실행 과정에서 원형 지시문을 다시 작성하거나 자동변형하지 않는다.

## 충돌 규칙

하위조항이 상위 원형과 충돌하면 하위조항만 무효다.
충돌을 이유로 원형을 수정하지 않는다.
